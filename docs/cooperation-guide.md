# 合作引导使用说明

默认开启，无需填写认领额度、任务数量或奖励命令。普通玩家点击配置好的 NPC 打开菜单；有 `bordergate.use` 和 `bordergate.command` 的玩家可使用 `/bg`。详见 [NPC 入口与权限](npc-entry.md)。

## 我能做什么

主页的望远镜显示推荐周期、任务标题、资源缺口和你的背包能投入多少。推荐可能是每日、每周或每月任务；下方三个周期按钮各自显示对应的任务标题和进度。点击进入推荐面板，只列出达到完成条件还需要的资源。三选四任务已完成两种时，只推荐再补一种，不要求填满第四种。

推荐优先选背包能补齐的资源，再选背包已有的资源，最后比较缺口比例和材料成本。其他完成路径仍然有效，可以去完整任务面板投入。

推荐面板左键投入按钮显示的数量。打开后即使背包物品变多，本次点击也不会超过原来显示的数量；缺口减少、背包不足、任务完成或到期时会再次检查。完整任务面板的普通左键按 `gui.deposit-amount` 投入，Shift＋左键投入背包匹配物品。

物品名称使用 Minecraft 翻译组件，跟随客户端语言；简体中文客户端显示“炼药锅、铁粒、粗铁”等，不显示 `item:MATERIAL` 内部代码。主页提示、任务详情、推荐、认领与全服任务列表共用名称规则，内部投料 ID 不变。可用 `resources.names` 为物品或货币指定服务器名称，例如 `item:CAULDRON: '炼药锅'`、`playercurrency:coin: '金币'`。

跨入新周期后，打开菜单会补齐尚未生成的当前任务，不等待每分钟检查；已发布任务不重抽、不改目标或截止时间。确实没有任务时分别显示“本服已停用”“没有可用的资源模板”或“手动目标为空或无效”，不再用笼统的“尚未配置”。升级只替换 JAR 并重启，保留已有配置和所有状态文件。

## 自愿认领与 Lands 领地

右键资源是个人认领；Shift＋右键代表选中的 Lands 领地认领。默认约缺口四分之一，向上取整，最多有效 1 小时且不超过任务期限。只有认领者本人能取消。认领只是计划，不扣物品、不占实际支付预留，也不阻止其他人贡献。

主页“我的 Lands 领地”或 `/bg lands` 只列出你是领主或被 Lands 信任的领地，显示 Lands 返回的成员数和本服历史贡献分。点击选择协作领地；已有有效选择优先，否则使用 Lands 当前编辑领地，只有一个可用领地时自动选用。多个领地且没有有效选择时不猜测归属。

BorderGate 不创建小队、不维护成员名单、不设人数上限。领地创建、信任、退出和管理全部使用 `/lands`。每次选择、领地认领和成功贡献都重新查询 Lands 权限。健康 API 明确确认失去权限时撤销本服领地计划；API 故障时暂停领地认领，不把故障当成失权误删计划，个人参与仍可用。

成功提交先抵扣本人计划，再抵扣当次选中且有权限的同领地计划；资源补齐或任务结束后关闭剩余计划。启用 MySQL 后计划及中文领地标签跨服可见，领地身份使用服务器作用域与稳定 ULID，不用名称冒认其他服领地。共享认领故障时暂停共享操作，不创建本地替代计划。

## 贡献反馈与个人记录

提交成功后显示贡献分、首次参与、补齐资源和连续参与天数；当次有效协作领地同时获得历史贡献分。领地改名不丢分，换领地不搬走旧分。没有有效选择或 Lands API 不可用时仅记个人贡献。失败和重复事件不加分、不重复抵扣计划。连续参与按任务时区及换期时刻计算，同一天不重复增加天数。

“我的建设记录”显示总贡献分、补齐次数、连续参与和当前协作领地。旧贡献记录保留，不重复发行首次奖励；反馈不额外发币、不改变 fixed／pool 分红。领地分数是本服历史展示，不宣称为跨服领地总排行榜。

## 城镇贡献榜

主页“城镇贡献榜”查看本服所有有有效贡献的 Lands 领地／城镇，无需加入对应城镇。授权命令用户也可用 `/bg towns`。“我的 Lands 领地”和个人榜提供切换入口。

按城镇历史累计贡献分从高到低排列；同分时按名称、稳定 ID 排序。每页45个，名次跨页连续，支持上一页／下一页和刷新，标记当前协作城镇。浏览与点击榜单均不会切换协作领地、认领、扣资源或发奖励；选择自己的协作领地仍在“我的 Lands 领地”完成。

分数沿用已有成功提交记账，不重算旧个人记录、不改变 fixed／pool 分红。改名采用 Lands 当前名称，稳定 ULID 保留分数；已删除或未有正贡献的城镇不进入当前榜单，历史分不删除。Lands API 故障明确显示暂不可用，不冒充空榜。

这是本服累计城镇榜，不是跨服务器领地总榜。国家榜、逐笔城镇明细及日／周／月独立城镇榜本轮未添加。

## 低频提醒与邀请

普通提醒每玩家至少间隔 10 分钟。同一玩家、任务、类型只发送一次；每个任务最多有新任务、接近完成、完成三种提醒。接近完成指还需一种资源，且该推荐资源已达到 75%。完成提醒可绕过普通冷却，显示结算后的实际边界和本服总上限。

主页铃铛或 `/bg reminders` 切换个人收件提醒。关闭后仍可手动查看和参加任务。

推荐面板可主动邀请伙伴。主动邀请与收件偏好分开：自己关闭提醒仍能发起邀请，但每人每任务最多邀请一次，两次邀请至少隔 10 分钟。接收者仍须开启提醒、拥有使用权限并通过普通去重／冷却。无人满足条件时，不保证有人收到。被冷却、个人开关或保存失败拒绝的收件提醒不消耗类型去重。

## 下一期的渐进难度

冷启动倍率为 1.0，日／周／月各自观察。至少有 3 个不同的同周期已结算自动任务后才调整，判断使用最新最多 6 个样本。大量失败或活动减少时降低；快速完成或活动增长且成功占多数时提高。单次最多约 ±10%，总倍率限制在 0.5–2.0；物品数量向上取整且不少于 1。

只改变新生成的自动任务。已经发布的模板、目标、期限和完成条件保留，手动任务也不缩放。长期失败且必要资源进度不足 25% 的材料会暂时避开；成功补齐或滑出观察窗口后解除。若没有兼容模板，回到正常任务池，不把服务停在空任务上。这里只利用本服参与记录，不能保证世界中每种资源都实际可获取。

## 可选配置与保存

以下都是默认值。老配置缺项会使用内置默认值，不必照抄整份配置。

```yaml
integrations:
  lands: true

cooperation:
  enabled: true
  reminders:
    enabled: true
  adaptive:
    enabled: true

gui:
  guide-name: '&b&l我能做什么'
  guide-title: '&8我能做什么'
  guide-deposit: '&a左键投入上方显示数量；不会自动投入其他资源'
  land-claim-click: '&b右键个人认领；Shift+右键 Lands 领地认领'
  claims-name: '&b认领计划'
  claims-title: '&8协作认领计划'
  lands-name: '&d我的 Lands 领地'
  lands-title: '&8我的 Lands 协作领地'
  personal-name: '&6我的建设记录'
  reminders-name: '&e个人协作提醒'
  reminders-toggle: '&e点击切换；关闭不影响手动参与'
  invite-name: '&b邀请伙伴协作'
```

已提供的 `gui.*` 文案键支持 `&` 颜色，缺项自动回退。动态资源数量、成员和贡献记录说明仍由插件生成。

升级保留 `config.yml`、`quests.yml`、`data.yml` 和 `cooperation.yml`。新合作文件版本为 3，保留个人记录、个人计划、提醒设置／去重、邀请、观察样本和倍率，另保存领地选择偏好及领地分数。旧小队和小队认领仅保留在 `legacy-squads`／`legacy-squad-claims` 历史档案，不转换成 Lands、不恢复成员关系。MySQL 保留旧 `team_id/team_name` 列名用于兼容存储；旧集体计划归零保留审计，不删表。

命令后备：`/bg guide`、`/bg lands [select <领地ID>]`、`/bg towns`、`/bg reminders`。`/bg cooperation` 查看服务与下一期倍率。已删除 `/bg team` 创建／加入／退出功能。菜单参与要求 `bordergate.use`；玩家手输任何主命令／别名及子命令还要求 `bordergate.command`，该权限默认仅 OP 拥有。管理员菜单／边界操作独立要求 `bordergate.admin`。NPC 代开使用控制台 `bordergate open <在线玩家名>`，只要求目标玩家有 `bordergate.use`。

各服只共享任务、提交、排名和认领；边界与月任务总上限始终独立。官方 Lands API 契约测试使用 7.12.7 接口夹具，不等于真实 Lands 插件或真人客户端联调；用户启动日志显示 Lands 9.3.0，尚未用该实际插件联调。FancyNpcs 动作语法按官方文档配置，未进行真人点击端到端验收；正式服未部署。
